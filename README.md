# E-commerce Sales Analysis — Excel

## Project Overview

This project is an e-commerce sales analysis created using Microsoft Excel.

The goal of the project is to clean, organize, analyze, and present e-commerce data in a clear and useful way.

## What I Worked On

- Data cleaning and preparation
- Data organization
- Data Dictionary
- Excel Tables
- Lookup functions
- Pivot Tables
- Data analysis
- KPI calculations
- Dashboard creation
- Business insights

## Dataset

The dataset contains information related to e-commerce orders, customers, products, sellers, payments, prices, freight, and customer reviews.

The data was prepared and organized in Excel before performing the analysis.

## Analysis

The analysis explores different aspects of the e-commerce data, including:

- Sales performance
- Product performance
- Regional performance
- Order information
- Customer and seller data
- Payment methods
- Review scores
- Freight and product prices

## Dashboard

An interactive Excel dashboard was created to present important KPIs and summarize the main findings from the data.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Functions
- Data Cleaning
- Data Analysis
- Data Visualization

## Project Structure

- `Ecommerce_Sales_Analysis.xlsx` — Main Excel project file

## Purpose

This project was created as part of my practical learning journey in Data Analysis and to practice working with a real-world style e-commerce dataset.
